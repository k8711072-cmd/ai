# Skill 收錄範圍

本目錄只放從個人工作流程改編、可供他人安全參考的範本：

- `ai-team-rule-router`：任務級別、工具選擇與團隊規則路由。
- `team-dispatch`：有證據與狀態來源的任務派工。
- `context-handoff`：跨工具、跨 session 與壓縮交接。
- `project-verification-gate`：網站、API 與服務驗證。
- `port-registry-guard`：本機服務與 Port 登記維護。
- `spreadsheet-data-safety`：試算表與正式資料安全。
- `document-extraction-quality`：文件/PDF/OCR 萃取品質檢查。

未複製平台內建或第三方 Skill 原始碼；有授權條件的內容應回到其上游來源取得。公司/客戶專屬流程與私有資料也未放入公開倉庫。部分公開 Skill 是經泛化的改編版，不等同私人環境中的原始版本。
