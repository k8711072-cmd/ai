今天學什麼

目標：會操作流程，不追求抄完整筆記

  1. 入門設定：登入、選模型、開個人智慧化連結
  2. 文字整理鏈：清單 → 表格 → 條列 → 匯出文件
  3. ACE 溝通原則：角色／任務／強化條件
  4. AI 視覺：截圖分析、菜單 OCR、影像生成
  5. 製造業五案例：異常報告、SOP、Excel、溝通

工具與模型選擇

建議主工具

  • Google 帳號登入 → 九宮格開 Gemini
  • 練習請選 Flash-Lite / 輕量版
  • Lite 可覆蓋約八成日常工作，較不易爆額度

講師提醒

  • 全程可用免費版完成今日練習
  • 若要付費：用一般 Gmail，勿用 edu
  • Google 家庭群組最多 6 人共用方案，帳號對話互不影響

必做設定（加一／加二）

  1. 登入 Google → 開啟 Gemini → 選 Lite
  2. 側邊欄 → 設定 → 先看「用量限制」
  3. 設定 → 個人智慧化服務
  4. 開啟 連結應用程式：Google Workspace、Google 搜尋、YouTube

連結打開後，才能把回覆整理成 Google 文件／試算表，並當行事曆秘書。

五個核心觀念

AI ≠ 搜尋

還沒想出關鍵字時，AI 更適合創意與會診。

新主題新對話

長對話會回頭掃前文，消耗額度。

指令要精準

「不要 A」不夠；要說「不要 A，換一種」。

欄名加引號

刪欄時用「欄名」成對指定，避免整列被刪。

最後才彙整

資訊問齊後，再請「整理成企劃書／報告」。

人要做最終確認

AI 負責草稿與整理，責任歸屬不可交給模型。

ACE 溝通原則

A
角色 Actor

你是資深導遊／品保工程師／生產主管助理…

C
任務 Context

要做什麼、給什麼背景與資料

E
強化 Enhance

限制、格式、排除條件、自檢要求

角色不會永久記住：每個新對話都要再講一次。

入門練習鏈（講義約 p.6）

  1. 給我十種台灣小吃
  2. 不要蚵仔煎，換一種
  3. 給我這些小吃的英文翻譯
  4. 整理成表格：小吃｜英文｜中文說明
  5. 改成條列；再刪除「英文翻譯」「中文說明」兩欄
  6. 複製到 Word → 表格設計 → 補框線

從問答到 Google 文件

示範：大阪五日行

  • 定角色：日本在地資深導遊
  • 要行程；再補地鐵／巴士站點與出入口
  • 可再問特定月份活動
  • 最後：「把以上整理成旅遊企劃書」

易錯

  • 太早要求企劃書 → 資訊不足
  • 只問行程不問交通 →「好看但走不動」
  • 未連結 Workspace → 開不出文件

AI 視覺：圖表與菜單

圖表（約 p.11）

  1. Win + Shift + S 擷取圖表
  2. 貼到 Gemini：「請分析此圖表」
  3. 「請將圖表改製成表格」
  4. 匯出 Google 試算表／重繪圖

菜單／街景（約 p.12）

  1. 上傳菜單圖
  2. 翻譯並製表：日文｜中文｜日幣｜台幣
  3. 加碼：預算 2500 日圓配三套菜
  4. 街景照可做景點辨識導覽

影像生成練習（加分）

  • 表情替換／遮瑕上妝
  • 老照片修復上色
  • 手繪草圖 → 真實產品
  • 虛擬試衣（保留姿勢）
  • 參考圖動作控制
  • 刪除路人、場景替換

適合電商樣片構想與教材示意；非正式量產驗證。

製造業應用五方向

  1. 產線異常日報 → 正式報告與主管摘要
  2. 口述經驗 → SOP 與測驗題
  3. 品質／客訴資料 → 改善方向
  4. 產線 Excel → 公式、樞紐、主管焦點
  5. 催交口語 → 對內／對外正式溝通

公司 know-how 在資深員工；AI 負責整理，不直接當「你們廠的標準答案」。

提示詞六段架構

元素說明製造業範例
角色請 AI 扮演職位助理你是製造業品保工程師
任務說明要完成什麼整理客訴原因並提改善方向
資料附件或貼上內容以下是八月不良紀錄
限制禁止編造、標不足不足處寫「需人工確認」
格式指定輸出樣式用表格：問題／原因／對策／負責人
檢核要求自檢最後列出 3 個可能遺漏風險

案例：異常日報作業鏈

  1. 上傳異常紀錄表（日期、班別、產線、現場紀錄…）
  2. 產出正式異常報告：摘要／時間／影響／原因／處置／追蹤
  3. 再要約 200 字主管摘要＋今日最需追蹤 3 條
  4. 產出待辦：事項、單位、期限、需確認資料、風險
  5. 品質檢核：邏輯跳躍、責任過早、資料不足卻下定論
  6. （進階）一次丟四段提示，要求整理成多個 Word 下載

可複用提示詞範本

你是製造業生產主管助理。
請將附件內產線異常記錄整理成正式異常報告。
格式包含：異常摘要、發生時間、影響範圍、可能原因、已採取措施、後續追蹤。
限制：
1. 不可自行編造資料
2. 資料不足處標示「需人工確認」
最後請列出依據與需人工確認項。

上傳檔寫「附件內…」；若是貼上內容則寫「以下是資料」再貼——兩者不可混用。

SOP 口述 × Excel 產線數據

口述 → SOP

  • 角色：教育訓練專員
  • 結構：目的、範圍、工具、步驟、確認項
  • 可改一頁一 SOP 或表格版
  • 再出 5 題選擇題＋職安缺口檢視

Excel 數據

  • 說明欄位：良率、不良率、達成率、停機
  • 提出主管關心的約 5 個焦點
  • 給可用公式與樞紐配置步驟
  • 產出主管摘要，不做假數字

案例：催交與跨部門溝通

  1. 上傳口語催交／多方意見紀錄
  2. 改寫為正式內部協調函（清楚、不指責個人）
  3. 再改寫對客戶說明與對供應商催料
  4. 萃取待辦：事項／對象／期限

課堂練習清單

最常見易錯點

  • 沒登 Google／選錯模型 → 進不去或額度秒爆
  • 同一長對話一直追問 → 額度被前文吃掉
  • 刪欄沒標欄名 → 整列消失
  • 未禁止編造 → 假原因、假負責人、假期限
  • 附件／貼上提示詞寫反 → 模型找不到資料
  • 把 AI 輸出當最終責任歸屬 → 未做人審

帶走這三件事

1. 流程

設定 → ACE／六段提示 → 產出 → 人審

2. 資產

把好用提示詞存成文書，每日可一次丟多任務

3. 定位

AI＝整理＋草稿＋檢查清單，不取代現場判斷
