# 課程重點與精華

來源：簡良諭老師《AI在工作中的實務應用－製造業零基礎個人實作》  
主辦：高雄市工業會  
整理用途：教學備課／學員複習精華（非原影片轉載）

## 一頁結論

用 **Gemini（Flash-Lite）** 完成「設定 → ACE／六段提示詞 → 產出文件／表格 → **人審**」。  
價值在整理、草稿、檢查清單；公司 know-how 與最終責任仍在人。

## 主題地圖（約 2 小時 46 分）

| 區段 | 重點 |
|------|------|
| 開場與設定 | 登入、選 Lite、用量、家庭方案、個人智慧化連結 Workspace／搜尋／YouTube |
| AI 初體驗 | 小吃清單→翻譯→表格→條列；新對話控額度；釘選對話；貼 Word |
| ACE | 角色／任務／強化；大阪行程＋交通＋活動→Google 企劃書 |
| AI 視覺 | 擷取圖表分析製表；菜單 OCR／換算／配菜；街景辨識 |
| 影像生成 | 修圖、試衣、草圖轉產品、動作控制 |
| 製造業應用 | 異常報告鏈、SOP 口述轉標準、Excel 產線數據、對內對外溝通 |
| 收尾 | 提示詞可複用；資料勿編造；人做最終確認 |

## 必記口訣

**ACE** = Actor（角色）→ Context（任務／資料）→ Enhance（限制／格式／檢核）  
製造業可再拆成六段：角色、任務、資料、限制、格式、檢核。

## 高價值操作

1. 連結應用程式後，最後才請「整理成企劃書／報告／Word」。  
2. 上傳檔寫「附件內…」；貼上內容寫「以下是資料」。  
3. 一律要求：不可編造；不足標「需人工確認」。  
4. 異常報告作業鏈：正式報告 → 主管摘要 → 待辦 → 邏輯／責任檢核。

## 易錯 Top 6

1. 選錯模型導致額度爆掉  
2. 長對話不開新對話  
3. 刪欄未標欄名  
4. 太早要求彙整文件  
5. 未禁止編造  
6. 把 AI 輸出當最終責任歸屬
