# AI 團隊規則與技能

這是從個人工作環境整理出的**公開分享版**，提供多 AI 工具協作規則與可移植技能範本。它不是原工作環境的完整備份，也不包含個人設定、憑證、公司資料、專案紀錄、Runner 程式或私有服務資訊。

## 內容

- `AGENTS.md`：通用代理人入口與安全底線。
- `CLAUDE.md`、`ANTIGRAVITY.md`、`OPENCODE.md`、`AIDER.md`：工具角色補充；角色依任務動態選擇，不指定永久指揮者。
- `docs/`：共用團隊運作與 context/token 原則。
- `.cursor/rules/`：可移植的 Cursor Agent 規則，不含個人權限設定或自動核准設定。
- `skills/`：由自建工作流程改編的技能範本；不複製平台或第三方技能套件。
- 技能清單與未公開內容的分類見 [`skills/README.md`](skills/README.md)。

## 使用提醒

開始使用前，先依自己的專案替換角色、資料風險、測試方式與工具能力；不要把範本中的能力描述當作已登入、已授權或已驗證的事實。每個專案只保留一份共用分工來源，其餘工具規則應短小並指向該來源。

請勿把 API key、token、密碼、cookie、`.env`、服務帳號憑證、客戶資料或未脫敏工作紀錄提交到公開倉庫。提交前檢查 Git diff 與敏感資料掃描結果。

此倉庫刻意不收錄原工作環境的設定檔、工作日誌、測試資料、供應商名稱、內部路徑/Port、個人帳號資訊及可直接操作私有系統的指令。公開版規則經過泛化，不能取代原環境的私有規則。
